# Manuscript figures

## Final layouts

Use `run_manuscript_figures.py` for the complete workflow. It now ends with
`final_publication_figures.py`, exporting assembled pages under
`Outputs/Figure2/` through `Outputs/FigureS1/` by default, replacing same-name figures at the final canvas
dimensions. `--output` selects the output root; each figure has its own subfolder. Figure 2 also includes separate a–d panel exports from the assembled page.
The individual entries below also export complete pages through the same
final-layout implementation. Plotting helper modules are internal sources.

The final reference PDFs contain Illustrator/pypdf assembly metadata. Their
layout is reconstructed with explicit panel rectangles; reference artwork is
not copied into generated figures. Data panels remain newly drawn from the
input atlas. Figure 1 is the supplied manual schematic and is not substituted.
Pass `--schematic /path/to/Figure1.pdf` to copy that supplied artwork unchanged
into the output set; it is not presented as a programmatically generated diagram.

The later source chain is: 33 for matched QC styling, 32 for lineage UMAPs,
36 for metadata-colour conventions, 37 for tissue-faceted pooled proportions,
65/61 for paired comparisons and 59/63 for doublet panels. Canonical marker
panels remain from 04; PCA calculations remain from 05/07. Final PDF placement
and formatting edits are applied by the assembly entry.

The corrected `controls without CNS inflammation (unspecific)` label is
preserved, as requested; it is not changed back to the older reference's
Unknown display. The h5ad is never modified.

Run all data panels from the code folder:

```bash
python run_manuscript_figures.py --input /path/to/final_atlas.h5ad --h5ad-dir /path/to/lineage_objects --output /path/to/figures
```

Individual entries can be run with `python -m figures.MODULE --input PATH
--output DIRECTORY`. Figure 4 recalculates matching, proportions and statistics
when `--input` is supplied. Without it, the bundled result tables can be plotted.

## Inputs and retained behaviour

- No expression integration, clustering, cell filtering or UMAP recomputation.
- Original plotting functions are extracted into modules without their
  top-level reads, hardcoded working-directory changes or unrelated analyses.
- Metadata and existing coordinates are loaded without the full expression
  object. Figure 3f reads only required logcounts gene columns; Figure 2 reads
  raw-count chunks for total counts and RPL/RPS percentages. These are memory
  adaptations, not expression transformations.
- Figure 2 uses stored `n_genes_by_counts` and `pct_counts_mt`, as original 08
  does. It recalculates total counts and ribosomal percentages from counts.
  This reproduces that plotting definition, not a fresh recalculation of all
  QC fields in the final shared-gene space.
- Figure 3 uses the supplied lineage coordinates. T uses `X_umap`; other
  lineages prefer `X_umap_logcounts_harmony` when available. It does not extract
  all lineage plots from the global UMAP.
- PCA identifies flags at distance z-score >1.5 within tissue/clinical groups
  with at least five samples. The inherited routines print candidate lists;
  no samples are removed.
- Figure 4 with `--input` matches explicit donor IDs from bundled GEO titles
  using original 61's parsing and unique-compartment rules. Original 65's
  GSM5264668 exclusion yields 40 pairs. Sample proportions include absent
  subtypes as zero. Two-sided paired Wilcoxon tests and BH across 25 subtypes
  use the original implementation, including numerical tie rounding and
  5,000 donor-bootstrap draws. Only three subtypes are plotted. Pair registries,
  audit decisions, per-pair values and all25 statistics are exported to Tables.
  No cell or sample is deleted from the h5ad. Dataset/disease sensitivity
  analyses and the all25 effect-size figure are not manuscript Figure 4 panels
  and are not generated by this entry.
- The original 63 tissue-separated doublet plots use a fixed score range 0–1,
  shared coordinate limits and existing doublet calls. Source-specific plotting
  checks are retained. The local skill audit-script dependency is omitted from
  the portable entry; PDF alignment/collision QA is not claimed as completed.
- Figure 5d is pooled cell composition, not a median sample proportion or
  disease-versus-control test. Only manuscript panels are exported; older ROE,
  disease-control heatmaps and dataset boxplots are not included.
- Arial is used when installed; DejaVu Sans is the portability fallback.
  Final page sizes and font sizes follow the reference PDFs. Individual entries
  now export complete pages rather than the earlier generic panel layouts.

Figure 1 remains the manuscript's manually assembled schematic. No new
schematic is substituted for the original artwork.
